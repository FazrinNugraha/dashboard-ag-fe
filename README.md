# Frontend Dashboard (React + TypeScript + Vite + Tailwind CSS)

Project frontend dashboard menggunakan React, TypeScript, Vite, dan Tailwind CSS.

## Setup & Instalasi

Dependensi sudah terpasang. Jika perlu install ulang:
```bash
npm install
```

## Menjalankan Server Development (Saat Ingin Dijalankan)

```bash
npm run dev
```

Server development Vite akan berjalan default di: `http://localhost:5173`

## Build Production

```bash
npm run build
```
